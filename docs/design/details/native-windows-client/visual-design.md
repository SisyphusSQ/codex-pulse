## macOS 参照与 Windows 转译

- 已查看仓库脱敏截图：`docs/assets/codex-pulse-overview-redacted.png`、`codex-pulse-projects-redacted.png`、`codex-pulse-popover-redacted.png`。这些是已保存的 Mac 画面，不代表当前机器上的同期运行结果。
- 概览借鉴紧凑额度带、年度指标与热图的一体化区域，以及消耗趋势/项目贡献双栏。Windows 保留原生 NavigationView，宽窗口展开，窄窗口使用图标导航；范围选择与页标题同排，自定义日期另起一行。
- 会话/项目借鉴列表与详情的明确分工，列表显示标题、归属和主要数值，详细来源证据保留在详情。筛选使用原生 Flyout，分栏保持拖拽和键盘调整，窄窗口提供返回列表。
- 概览项目与会话排行采用整行原生按钮：序号、名称和次级归属在左，Token 与成本在右；长名称省略并保留提示及辅助功能名称。活动分布与高消耗会话在宽窗口并排，窄窗口按阅读顺序上下排列。模型构成与成本表归入可展开明细，避免趋势下方堆叠所有信息。
- 设置采用 Windows 的左侧说明、右侧控件布局；控件宽度受可见区域约束，窄窗口上下排列。保存草稿和即时外观修改维持原有边界。
- 托盘将客户端选择和主窗口/刷新/更多操作固定在上下两端，内容独立滚动。额度名称与余量同排，次要操作收进菜单。
- 图表使用原生向量：趋势折线与面积、刻度、精确值提示；未知点断线。年度热图添加月份/星期并随宽度伸缩，未知格与已知零保持不同。构成图使用颜色图例、独立数值与百分比。
- 字体依据 [Windows Typography](https://learn.microsoft.com/windows/apps/design/signature-experiences/typography) 和 [WinUI FontFamily](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.media.fontfamily?view=windows-app-sdk-1.8) 使用系统界面字体与中文回退，不安装外部字体。

## 信息与视觉

- 核心任务是快速判断用量、成本、额度余量和数据可信状态，再下钻会话或项目。汇总优先展示当前范围指标和客户端额度，年度活动为独立的最近 365 天。
- 主窗口使用分组侧栏、单一页头和范围工具栏。自定义范围才展开日期输入，预设范围的日期/时区保留在提示及页面统计范围中；语言与主题归入设置。
- 超宽窗口主内容列最多 1440 个逻辑像素，设置表单最多 1040；两者左对齐且在窄窗口填充可用宽度。年度热图格子保持正方形，尺寸取整并限制在 6–24 之间，必要时局部横向滚动。
- 沿用 WinUI 系统字体资源和原生控件，不引入第二套 UI 框架。页标题 28、区块标题 18、正文 13–14、辅助文字 13（行高 20）；图表坐标与月份/星期按局部空间使用 10–11。统计条关键指标 24、输入/输出分项 20，独立额度页余量 32。避免给日期或说明文字套用大数字样式。
- 卡片使用系统主题表面和细边框，12 圆角、20 内边距；卡片间距 12–16，页面区块间距 20。图表不使用装饰阴影；状态色必须同时有文字说明。
- `App.xaml` 集中维护公共样式，`PresentationControls` 维护卡片、指标、分组标题、表格及自适应组合。浅色、深色和系统主题沿用动态资源。
- 表格用于同类字段比较，列表与详情用于会话/项目，卡片用于独立账号、额度或图表。避免同一额度区多层卡片嵌套。

## 数字与单位

- Token 对齐 macOS `TokenQuantityFormatter`：中文以万、亿为量级（普通展示在单位前留空格），英文以 K、M、B 为量级；普通最多两位、紧凑最多一位小数，不强制补零。舍入跨过下一级阈值时提升单位，例如英文 999,999 显示 1M，中文 99,999,999 显示 1 亿。
- Token 格式仅用于 Token 字段，轮数、会话数和账号数仍为整数。C# 使用 decimal 做展示缩放，保留原始 int64，不改 Go 计算。
- 美元使用 `$` 与两位小数；小于 0.01 的非零金额保留四至六位，避免显示为真实零。这是保留现有精度语义，未照搬 Mac 某些卡片固定两位的限制。
- TPS 保留两位小数，活跃耗时从毫秒换算秒并保留三位小数，与 Mac 一致；百分比保持原有额度与缓存命中率各自精度。
- 节奏差保留 `pp`（百分点）与最多两位小数，表示剩余比例相对均匀节奏的差值；macOS 当前将其舍入为整数并显示 `%`。这里保留 Windows 原有明确单位，未将百分点误写为剩余百分比。
- 内存、磁盘与文件大小对齐 macOS `bytesText`：按 1024 进位，单位标签为 B/KB/MB/GB/TB，固定一位小数；这是沿用 Mac 的显示命名，不改变字节数据。测试覆盖零、1023/1024 边界、各量级和未知值。
- 图表摘要和图例使用缩写，Tooltip 与图表明细保留精确整数；未知显示破折号，已知零仍显示零。
- 项目每日贡献的坐标、明细和范围使用响应的统计时区，避免跨日时与机器时区混用。测试覆盖跨日期及夏令时重复小时；不改变 Helper 的聚合桶。
- `UnitPresentationTests` 复用 macOS 的中文、英文与跨量级示例，并覆盖未知、负值、int64 上界和极小金额。

## 状态与行为

- 正常就绪不重复显示状态文字；部分覆盖、未知、过期、失败、取消与恢复受阻仍明确显示。未知不显示为零，API 等价估算不显示为订阅账单。
- 后台刷新保留同一上下文的已显示数据与覆盖提示，通过页脚进度环和固定宽度的刷新/取消按钮反馈进度，避免新增状态行和按钮挤动布局。概览展开的模型、每日、星期小时与技能明细在本页刷新中保留展开状态。
- 筛选按钮显示已生效条件数；零结果提供调整日期或条件的提示。窄窗口详情的返回按钮固定在滚动区域外，项目贡献与概览排行下钻后直接进入详情。
- 控件保留原有权威数据、取消、草稿、账号绑定与隐私复制边界。仅调整展示，不增加 Helper 接口或 C# 业务计算。
- 窄窗口时卡片和区块工具栏换行，表格/图表局部横向滚动。键盘焦点、工具提示和辅助功能名称保留。

## 验收

用户于 2026-10-29 明确要求以简体中文与浅色界面为主要验收环境，基本不使用深色。后续优先检查中文换行、数字与单位对齐、白色背景下的卡片层次和控件边界；深色仅作为兼容性证据，不代替主验收。

以实际 WinUI 页面为准，构建或静态检查不等同视觉验收。比较汇总、概览、额度、会话/项目、设置和托盘；核对中英文、深浅主题、常用与窄窗口、长文本和大数字、部分/空/失败状态。100%/150%/200% 缩放须分别记录实际证据，未执行不记通过。

真实 Home 启动须读回 App/Helper 环境、runtime 私有 ACL 与 preferences 的 Home 物理身份。模拟数据只用于状态测试，不能代替真实产品验收。当前机器无法运行的 macOS 对照应明确记录为源码参照，不能宣称已完成双端画面对比。
