# 模型价目、用量成本与账号订阅

## 目标与范围

在现有中心增加独立价目表，账号内额度/节奏与全局用量/成本分别呈现；按已选方案1，账号为独立入口，用量集中为概览/模型/采集来源。覆盖 Codex/ChatGPT、Cursor、Grok；复用现有 Go 成本计算、历史价格证据、事实去重与账号仲裁。

- 价目表含模型价格和订阅与额度两个页签。公开目录覆盖可获得模型，不使用 Mac 当前展示隐藏规则；实际观测但无费率的模型显示未知。模型、计费平台、模式、单位、价格版本、来源和核对时间分别保留。
- 官方当前参考价与本机历史目录分别展示；当前价格不改写历史消耗。多模态保留其单位。金额显示两位，极小正费率显示阈值；底层精度不变。
- 用量页复用中心时间/来源/模型筛选，展示输入、缓存、缓存写入、输出、reasoning、总量、API 等价估算与上报费用；模型趋势使用真实日/模型数据，不比例分摊。Codex/其他 Provider 费用名称与 Mac 一致；unknown/partial/zero 保留。
- 账号列表和详情左右分屏。各实际额度窗口摘要同时可见；选中窗口节奏在 Credits 长明细之前；库存、到期与 reset 分开，原始证据收进详情。
- 中心管理员可为已确认账号维护备注、手动套餐、每月续费日或会员到期日、IANA 时区。Web 统一维护，不回写 Mac。手动值独立存储，不被设备上报覆盖；同邮箱不合并。
- 月续费日 1–31，短月按月末，经过日期后滚动下月；完整到期日保留过期状态。日期由 Go 计算，不把 quota reset 或 Credits expiry 转成会员日期。

## 实现边界与失败语义

新增 catalog 只读域、subscription 设置域，遵守 Starter controller/service/repository/DO/DTO/VO。所有接口要求 admin；写接口复用 Cookie、精确 Origin 与 CSRF，严格字段白名单与乐观修订控制。不存在账号返回 404，非法字段返回 400，修订冲突返回 409，未读取成功不得提交默认覆盖。

订阅设置新增单独表，MySQL 为目标、SQLite 为开发数据库；DDL 双 dialect 同步，显式升级、校验旧版本摘要并保留原数据，HTTP 启动不自动改结构。目录作为可审核的版本化公开数据随代码交付，不在页面访问时抓取网页或使用 Agent 凭据。

统计继续按中心已接受事实复用整数定价：Codex 缓存是 input 子集、reasoning 是独立 output 类计数；Cursor cache read/write 独立，reported charge 中的费用不重复相加；Grok reported/estimated 分开。本机历史价格/费率仍为统计依据，不从当前价目重估旧记录。独立模型用量页不继承账号选择；无可靠关联的 Home 历史只属于全局/来源用量。

## 排除范围

三台 Mac 订阅日期双向同步、自动扣款或续费、Agent 登录与秘密托管、原始 JSONL/正文同步、修改本机采集生命周期、生产部署与正式发版。App 退出停止采集和上报，重开增量补采及续传。

- 新路由匿名/collector 拒绝，写入缺失 CSRF、非法账户与非法日期拒绝；设备上报不覆盖设置。
- 用量真实 API、模型日趋势与成本分类、未知与已知小计、价目跳转可操作；账号节奏主信息在明细之前，桌面和 390px 窄屏可用。
- 聚焦 Go/HTTP/Web 行为验证、类型检查、AntD lint、构建；本地 loopback 独立 SQLite 浏览器读回。原始证据位于忽略的 `.artifacts/multi-machine/catalog-usage/`。

## 已批准设计中的模型缓存指标（2026-10-03）

正式模型分析增加统计范围和各模型的 `cache_hit_rate`，由 `statistics/usage` 返回 `basis=range_cached_input`，与会话的 `lifetime_cached_input` 明确区分。Codex 的全部已接受日桶都具有已知输入/缓存计数时，使用相同的缓存输入÷全部输入、basis points四舍五入口径；任一计数缺失、缓存大于输入或输入为零时不拿已知小计生成比率。跨会话累计使用大整数，不受int64或浏览器整数精度限制。当前其他平台及混合平台保持未知原因，不套用Codex的输入语义。

这只是只读查询的附加字段，不改变上报、表结构、历史成本、原生会话缓存指标或认证权限。旧中心缺少字段时Web保持未知，不在浏览器计算比率。


## TOO-523：模型按发布时间倒序（2026-10-03）

价目表默认全部目录按已确认的模型发布时间从新到旧显示，替换近期已使用优先和名称排序；保留近30天已使用筛选、平台/搜索/版本/单位和历史价格。常驻日期，发布来源可展开。Server 将官方 release notes/公告的日期作为独立内嵌元数据，所有计费条件共享对应型号的发布日；日期未知置后，不使用价格生效边界、核对日或型号序号推断。无数据库、原生计价算法或上报契约修改，不重估历史成本。
