## 本轮设计决定

- 全年活动始终在概览最上方，年度范围独立；正方格随宽度增大，最小14px、3px间距，窄屏仅日历内部滚动，保留365日和固定星期。
- 趋势只用按模型的折线，Token/API成本切换保留；未知日期为断点，不增加柱状/折线切换。
- 公共筛选收进紧凑工具条：7/30/90天与自定义直接可见，来源放筛选浮层，报告时区在自定义日期内，已选条件可移除。账号、来源和价格不显示无用途的日期字段。
- 按最新用户修正，实际采样改为普通蓝色实线，跨缺口连接两端已有观测，历史中位基线保留紫色虚线。默认隐藏采样圆点，悬停查看数值；缺失时段仍为NULL，连线仅作趋势参照，不新增观测、插值事实或预测证据，也不延伸到最后观测之外。密集样本含240条记录及一段缺失，单独提供公共组件设计。此前参考Mac的stepEnd阶梯/断线方案已被用户明确否决，不能当作当前设计要求。
- 节奏与历史的结构按Mac客户端重新组织：四项指标（已使用、周期进度、节奏差、历史基线），同图展示本周期/上一周期/近四周期中位数/理想节奏，图下并排保守耗尽推算与同进度对比，实际采样和周期明细可展开。陈旧或冲突时当前指标未知，只保留可查历史；稀疏状态不生成预测。仍保留用户已确认的普通采样实线连接两端，不回退被否决的阶梯/断线。
- 预测暂停原因放在“节奏评估”旁可点击/悬停的醒目图标中；主值未知与短空态仍可见，去掉整块蓝色说明。
- Credits优先展示当前可用；最后观测作为次级证据，到期表不显示单页分页。到期与reset分开，详情状态降为小标签，原时间和来源ID可展开。
- 同邮箱不同原始账号仍分开。Codex窗口与Reset Credits不移植成Cursor/Grok假窗口；缺少观测的账号保留未知。
- 订阅表单保留账号备注、套餐、每月续费日/完整到期日/未设置及日期时区；它们独立于真实额度reset。设计稿修改只在当前页面内存生效。
- 项目/会话详情留在页面左右分屏。窄屏使用列表/详情逐级进入与返回；导航使用Drawer，记录详情不使用Drawer。
- 按用户看过首轮后的修正，概览补齐当前产品的客户端/模型明细及分布、工具技能、年度统计、范围质量与项目会话入口；不以视觉精简删去现有信息。所有页面标题下的副标题统一删除，其他页面保留已认可结构。

## 数据与实施边界

所有账号、ID、项目、会话、数值、价格和配对码均为合成样本。`DEMO-4826`不能用于真实服务；配对、改名、关联、订阅和撤销只改变当前设计组件的内存状态，重开故事恢复样本。不访问中心API、SQLite、真实Home、JSONL或Agent凭据，不建立浏览器管理会话。

筛选、搜索、日期、模型和指标用于评审控件及交互；日期可改变示例折线范围，范围摘要与部分明细采用固定代表样本，不构成统计对账或实时查询能力。价目仅展示代表行，不是现有中心完整目录；历史版本选择用于评审价格证据层级。业务实施继续由Go返回范围总量、去重、历史成本、窗口和预测，不能把设计稿的样本计算移入业务页面。

独立Vite配置不继承业务工程`/api`代理。依赖为锁定的Storybook 10.6.1、React/Vite adapter和Docs addon，与现有React19/Vite8兼容。样式统一使用`ds-`命名空间；业务入口不导入`src/design`，正式Web静态产物不包含设计稿。

TOO-517 的独立设计阶段不改变Server/SQL/上传协议/鉴权、原生App生命周期或生产运行配置。设计批准后，正式 Web 已按真实中心契约实现相同信息层级；18085 托管新版业务构建并复用原合成SQLite和已有浏览器授权，6007仍为独立设计预览。业务入口继续不导入设计样本。正式接入另补充Codex范围/模型缓存命中率的可选查询字段，共享Go算法并保留生命周期口径；不迁移数据库。开发对照、异常语义及验证记录见根`design-qa.md`与[多机runbook](../../../test/multi-machine-reporting.md)。MySQL、三机、生产与Master验收不在本卡证明范围。

## 启动与检查

在仓库根目录运行：

```sh
npm --prefix server/web ci --ignore-scripts
npm --prefix server/web run storybook
```

默认只监听`127.0.0.1:6007`，避免占用家庭服务现有6006。无须启动后端或数据库。

```sh
npm --prefix server/web run typecheck
cd server/web
antd lint src/design --format json
npm run build-storybook -- --output-dir ../../.artifacts/storybook
npm run build
```

开发验证看浏览器实际渲染与核心交互、桌面/390px布局、控制台及同图对照；不为可逆图稿新增镜像实现的单元测试。原始截图与构建保留ignored `.artifacts/multi-machine/storybook-20261003/`，提交摘要见根`design-qa.md`和多机runbook。提交推送收尾不重复测试。
