# TOO-524 中心用量与授权优化

实现范围仅为中心 Web、中心统计查询和结构化上报导出；原生 App 的工具/技能分析保留。任务：[TOO-524](https://linear.app/sisyphus-sq/issue/TOO-524)。开发验收在独立 Storybook 内使用合成 API；生产部署和三机真实数据验收待用户确认后安排。

## 额度与账号

普通额度与 Reset Credits 查询在 SQL 分组/排名前排除 `account_key IS NULL`，不删除记录。Codex 固定 `limit_id=codex`：Pro/prolite/pro5x/pro20x 只显示 10080 分钟，Plus 显示 300 与 10080 分钟。其他历史窗口留在库中，不进入摘要、节奏和诊断窗口投影。套餐尚未取得时不猜窗口；已知套餐缺失窗口显示“未取得”。窗口和实际用量分别管理，不通过套餐生成额度百分比。内部四周期维护使用明确 `RawHistory` 扫描，不受用户侧过滤影响。

账号页保留节奏与历史、可信状态和原观测时间，移除来源证据标签及其请求、来源详情入口。Reset Credits 到期明细保留。未归因用量仍属于全局 Session/项目统计，不随额度账号过滤而消失。

## 来源与统计

来源 ID 沿用鉴权得到的 collector ID，显示名称从中心 client 表读取；请求正文不能指定来源身份。会话列表、详情和高消耗会话显示机器名称集合；关联项目显示成员来源机器集合。改名后读新名称，撤销授权后历史名称仍可读取。采集机器不被当成实际执行机器。

新增 `GET /api/v1/statistics/source-usage`，共用范围/平台/模型/项目/来源过滤与 admin 鉴权。在同一只读快照内流式读取 Codex 来源，先按同会话同机器仲裁多个 Home，再统计其自己的贡献；机器小计允许重叠，不能求和成全局总量。Cursor/Grok 不展示为 Codex 用量，未取得数据保持 NULL。复用来源、事实、单会话字节预算和请求超时，超预算明确失败。

`summary` 在当前统计扫描中返回 `activity_granularity/activity_timeline/top_sessions`。单自然日按小时，其他范围按自然日；桶为 UTC 毫秒 `[start,end)`，IANA 时间用于显示。小时保留夏令时重复小时，未知桶不补零。Top5 按范围内 Token 倒序，排除 `unassigned_usage` 汇总记录，保留项目和机器名称。会话在各桶内分别去重，桶会话数不能相加成范围唯一会话数。

首页顺序：时间/平台/机器筛选、置顶全年活动、当前范围 KPI、活动柱图与高消耗会话、星期与小时热力图、机器 Codex 用量、模型趋势与构成。首页默认今天，列表默认30天；统一今天/7天/30天/90天/自定义。点击日柱选择该自然日，点击机器筛选整页，点击高消耗会话携带范围与来源进入会话详情。年度活动仍为独立365天范围。星期小时热力图使用年度同款正方形格子、圆角/间距/色阶；按用户最终调整收窄左活动卡片、紧凑星期热力图，增加右高消耗会话宽度。热力图24列均分卡片内容宽度，不设置独立固定宽度或最大/最小宽度，不通过缩放制造缩小效果。原版年度、范围汇总、模型趋势、平台/模型明细、采集来源、平台分布与模型分布卡片全部保留，仅移除工具与技能卡片。

## 表格与授权

用量和模型贡献表默认 Token 倒序，可切成本/输入/输出等字段；来源和设备表默认最新采集时间倒序；费率表默认发布时间倒序；TPS 轮次默认开始时间倒序；节奏历史默认观测时间倒序；Credits 到期明细默认到期时间倒序。未知值置后，排序比较原始精确十进制数。

会话和项目列表沿用服务端分页前最近活动倒序，将模型与排序控件直接显示；选择 Token、成本、名称和升/降序对完整结果生效。额度证据 API 的后台诊断分页默认观测时间倒序，但 Web 不再加载该接口。

设备与授权页隐藏已撤销项，按创建时间倒序分别展示 APP 授权（collector）和管理浏览器授权（admin），保留现有签发/管理码确认/改名/撤销及 CSRF。撤销只停止接入，不删除历史事实和机器名称。

## 停止工具与技能上报

新导出不查询工具/技能表；新队列快照在摘要计算前移除 invocations。中心不新增、替换或统计调用记录，历史调用表保留。原生本地功能保留。

协议 v1 的旧字段保留为过渡兼容：升级前已经入队的不可变正文/分片不能原位改写，否则会破坏摘要与重试幂等。旧队列和尚未升级客户端仍可按原摘要完成传输；中心先校验完整旧快照，再在业务仲裁与 canonical 投影中忽略调用信息，不写调用表。来源原始白名单快照保留旧摘要所需字段，用于同 revision 与已完成分片重放。**要停止三机持续发送新调用信息，三机 Helper 均需升级；仅部署中心不能证明这一点。**

## 验收与边界

聚焦验证：额度套餐过滤/未归因与维护扫描、来源重叠及缺失、IANA/DST小时、范围Top5与汇总记录排除、旧分片原子性/重放/损坏、授权列表与撤销、真实页面路由交互、精确排序和失败状态。预览入口与证据见 [验收说明](../../../../server/docs/test/too-524-acceptance.md)。没有新增依赖或数据库迁移；生产 MySQL、中心部署和三机升级不由本机测试推断完成。
