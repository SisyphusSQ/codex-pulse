# 已发布 SQL

当前交付：[v0.15.1](v0.15.1/README.md) 归档分片暂存与设备同步的 v3 SQL，保持与运行时 schema 的精确字节一致；执行证据单独记录。v0.15.0 初始结构的历史说明保留在 schema/unreleased，未补造过去的发行档案。

每个版本目录保存本次实际交付的 SQL 和 README，README 至少包含：

- 版本、代码 tag/commit、发布日期及根 changeLog 入口。
- SQL 文件清单、SHA-256、用途、前置条件和明确执行顺序。
- 对应完整 schema 的路径和代码版本，供新环境定位。
- 已有验证结果、失败处理与已知限制。
- 各目标环境的执行状态和证据链接；“已发版”不等于“已执行”。

这里只归档交付事实；已发布 SQL 保持不可变。无 SQL 的版本不建目录。详细规则见 [SQL 组织与版本交付](../README.md)。
