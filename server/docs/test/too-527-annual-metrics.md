## 当前连续天数后续修复

旧算法在回溯至无记录日期后丢弃已收到的连续段，导致实际连续活动显示未知。改为按中心自己的已收到记录计算：尾日有活动从尾日计数，今天没有活动证据时允许从昨天计数；遇到无记录或明确零日期停止，不连接空白日期。全年完全没有观测仍返回 NULL，热力图/覆盖未知语义不改。算法仍复用年度日序列，不增加 SQL、表或请求。正式结果在 Linear TOO-527 回写。
