## 迁移与启动审查

首次 DEV 启动失败发生在数据事务提交后的 `RELEASE_LOCK`。读回 v9 标记和用量摘要确认了迁移结果。DEV SeekDB 测试发现仅关闭连接后，竞争连接在 4 秒内仍可能拿不到锁。保留持锁连接上的显式释放，把独立预算从 3 秒延长到 15 秒。4 秒延迟释放、迁移失败、取消和显式释放失败的聚焦测试通过。DEV 的两连接测试验证显式释放后能重新取锁。

在 DEV SeekDB 1.2 的临时库恢复原 DEV v8 备份，用修订候选二进制执行实际 HTTP 启动。首次启动在 2.859 秒达到 `/ready`，迁移 11,672 条记录，13,923 条有效记录的完整字段和 Token 总量一致。随后重启在 0.612 秒达到 `/ready`，用量和 schema 标记保持一致，`db check` 通过。临时库已清理。

混合批次同步替换大快照时，只切换生效版本，旧大版本由已有后台流程回收。回归测试通过。
