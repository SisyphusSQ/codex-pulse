日期：2026-11-08；基线 `7df6b63`；[TOO-700](https://linear.app/sisyphus-sq/issue/TOO-700)。以下为开发阶段验证证据；后续按用户授权交付 Server v0.17.7，最终部署状态见 TOO-700 回写。schema 保持 v7，无 DDL、新依赖、生产配置或业务事实写入。

## 改动与正确性

- 模型及历史价格目录复用既有 `PublishedUsage`，读取未分代会话的内联事实和当前发布代际。排除已被替代的内联事实、旧代际、未发布暂存及删除会话；空发布快照不能复活旧目录记录。
- 新代际普通用量查询在不超过 168 小时且没有会话/项目/机器/搜索限制时提示已有时间索引。Provider、模型及 unknown 谓词仍由原查询执行；其余范围不提示该索引。不会把物理行去重、提前分页或改变精确整数。
- 年度仍使用原 HASH 提示，来源仲裁、分片校验、无时间覆盖及缓存策略没有改动。

## 真实数据库只读对照

现场为 SeekDB 1.2.0 / MySQL 兼容协议，schema v7；不是独立 MySQL 8。每一对 SQL 在同一 REPEATABLE READ 只读一致快照执行，结果排序后按多重集完整对照并记录 SHA-256，不把跨事务样本称为同一全局时点。执行顺序交替为旧→新、新→旧；正文结果只在内存中比较，忽略目录中保存摘要和计划。

| 目录 | 旧条数 | 新条数 | 独立对照条数 | 新旧差异 | 新与独立对照 |
