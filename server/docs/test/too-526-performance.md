# TOO-526 全部接口与 SQL 性能验收

范围为中心 Server 与内嵌 Web，不更新原生 App，不新增 schema。已完成第一轮正式部署与真实 HTTPS 验收，默认卡片持续刷新修正另由后续 PR 交付。

## 已取得证据

- 现场数据约 53.4 万用量事实、4129 会话、4457 来源快照（payload 约 287 MB）、7.1 万额度观测。统计只读 probe 的优化前后八个 summary/usage 响应逐项一致；全局与指定设备来源分别有隔离回归。
- 同机真实管理会话 HTTPS 基线：summary 今天 1349 ms、7 天 1839 ms、30 天 3347 ms、90 天 6547 ms；usage 为 64/587/2112/5325 ms；今天机器来源 4447 ms；30 天会话/项目列表 2835/3047 ms；详情 63/187 ms；目录 609 ms；额度 623 ms、账号 4 ms、节奏 292 ms；授权/版本/设备点读 2–10 ms。这些是单轮样本，负载影响显著。
- 目录 SQL 两轮：模型 218–238 → 146–157 ms，价格 365–400 → 247–276 ms；19/34 行的排序摘要完全一致。测试没有使用真实业务写入来制造统计。
- 开发 focused race：statistics_srv 与 HTTP 包通过；Web 四文件共 15 项通过，TypeScript 与全 src AntD lint 通过。最终覆盖全部业务 service 与 HTTP 的非 race 场景也通过；懒加载调整后前端三文件 12 项和类型检查通过。未运行根全仓长测或 CI。

## 路由覆盖与运行边界

所有业务路由均纳入隔离 HTTP 场景（配对、session/logout、配对签发/撤销、客户端列表/改名/撤销、batch/sync、项目关联、统计卡片/列表/详情、设备、目录、额度/账号/节奏、订阅读写），健康/ready/metrics 和静态 Web 由 Server 场景覆盖。成功写入、幂等、CSRF、身份隔离与拒绝权限使用合成数据。正式环境读接口使用临时 admin，会话结束撤销；正式写入检查只针对测试授权与可控请求，不改真实订阅或项目关系。逐路由生产状态及边界将在部署后记录。

## 自查

鉴权在缓存前执行，缓存键保留全部资源筛选；SQL 参数化；不输出凭据、原始来源 payload 或危险 HTML。单工作者、deadline、32 条目/64 MiB、取消和停服生命周期有界。冷失败报错，刷新失败保留旧值并提示；精度、来源仲裁、成本舍入和快照语义保留。跨卡片为各自计算快照，页脚统一说明后台更新，不声明同时刻原子结果。

## 复审发现与第二轮

默认预热条目不能按普通筛选五分钟闲置停刷，否则隔很久打开首页会先见旧值。第二轮使上海时区今天和年度四个默认投影持续活跃；其他筛选继续闲置暂停。新增模拟无人浏览的回归场景，验证仅默认条目被续活、其他筛选不续活。

用户现场指出每卡片计算时间说明破坏并排卡片对齐；第二轮移除所有卡片旁缓存说明，页脚统一说明每分钟更新与延迟，仅当前页面活跃查询失败/陈旧时追加统一提示，历史筛选不触发提示。

第二轮开发验证：统计服务 race 与默认续活聚焦场景通过；页脚/首页/活动三文件 13 项和类型检查通过。

DEV 与正式更新至 v0.15.2+performance.121fefd；来源、摘要、PID/运行状态与 ready 一致，schema v4、配置与既有授权保持。第二轮在线备份第一次受 SeekDB 查询期限中断，下一次有界备份成功并生成校验摘要；失败文件未作为备份使用，未修改全局超时。

正式 HTTPS 24 个并发热 totals 全部成功、后台计算时刻跨分钟推进；内嵌 bundle 存在统一页脚且无卡片“统计截至”。已通过现有正式 Chrome 会话刷新和滚动验收：平台/模型并排卡片恢复对齐、卡片时间说明数量为零、页脚为新版本及统一更新规则。临时验证授权 logout 后 totals=401。

7 天会话/项目为 365–388 / 270–280 ms，30 天 606–613 / 532–571 ms，90 天 1249–1270 / 1198–1231 ms；额度页实际摘要 285 ms/3467 bytes，选中窗口 evidence 409 ms、pace 270 ms，目录 418 ms。不是稳定分位数。

停止本轮的依据：首屏缓存热路径已不执行昂贵 SQL，实时列表的剩余冷成本与范围事实量相关；现有计划未显示更有收益的索引证据。进一步压低宽范围冷查询需要增量聚合或更多缓存，维护成本增加，不据短期负载波动继续修改正确性路径。不宣称绝对不能继续优化。用户后续年度展示扩展由 TOO-527 承接，不增加 SQL。
