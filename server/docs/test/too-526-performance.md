# TOO-526 全部接口与 SQL 性能验收

范围为中心 Server 与内嵌 Web，不更新原生 App，不新增 schema。生产部署和 HTTP 复测结果将在部署后回写；本页开发结果不冒充生产验收。

## 已取得证据

- 现场数据约 53.4 万用量事实、4129 会话、4457 来源快照（payload 约 287 MB）、7.1 万额度观测。统计只读 probe 的优化前后八个 summary/usage 响应逐项一致；全局与指定设备来源分别有隔离回归。
- 同机真实管理会话 HTTPS 基线：summary 今天 1349 ms、7 天 1839 ms、30 天 3347 ms、90 天 6547 ms；usage 为 64/587/2112/5325 ms；今天机器来源 4447 ms；30 天会话/项目列表 2835/3047 ms；详情 63/187 ms；目录 609 ms；额度 623 ms、账号 4 ms、节奏 292 ms；授权/版本/设备点读 2–10 ms。这些是单轮样本，负载影响显著。
- 目录 SQL 两轮：模型 218–238 → 146–157 ms，价格 365–400 → 247–276 ms；19/34 行的排序摘要完全一致。测试没有使用真实业务写入来制造统计。
- 开发 focused race：statistics_srv 与 HTTP 包通过；Web 四文件共 15 项通过，TypeScript 与全 src AntD lint 通过。最终覆盖全部业务 service 与 HTTP 的非 race 场景也通过；懒加载调整后前端三文件 12 项和类型检查通过。未运行根全仓长测或 CI。

## 路由覆盖与运行边界

所有业务路由均纳入隔离 HTTP 场景（配对、session/logout、配对签发/撤销、客户端列表/改名/撤销、batch/sync、项目关联、统计卡片/列表/详情、设备、目录、额度/账号/节奏、订阅读写），健康/ready/metrics 和静态 Web 由 Server 场景覆盖。成功写入、幂等、CSRF、身份隔离与拒绝权限使用合成数据。正式环境读接口使用临时 admin，会话结束撤销；正式写入检查只针对测试授权与可控请求，不改真实订阅或项目关系。逐路由生产状态及边界将在部署后记录。

## 自查

鉴权在缓存前执行，缓存键保留全部资源筛选；SQL 参数化；不输出凭据、原始来源 payload 或危险 HTML。单工作者、deadline、32 条目/64 MiB、取消和停服生命周期有界。冷失败报错，刷新失败保留旧值并提示；精度、来源仲裁、成本舍入和快照语义保留。跨卡片为各自计算快照，显示计算时间，不声明同时刻原子结果。
