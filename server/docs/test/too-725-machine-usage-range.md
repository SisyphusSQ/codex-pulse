# TOO-725 机器用量日期范围验收

2026-11-23，开发分支 `suqing/too-725-source-usage-range`，基线 `37c11a4`。在 SQMC04 的隔离 DEV SeekDB 1.2.0.0 库使用线上 Codex 结构化数据。来源、分片及机器归属来自同一个可重复读只读事务，采集凭据摘要在导出时重新生成。

## 逐台对账

样本包含 3,733 份来源、107 个分片清单和 597 个分片。接口包含 5 台机器，其中 1 台已撤销，页面展示其余 4 台。隔离库从 v9 启动迁移，首次就绪用时约 26 秒，随后读回 v10 结构以及 3,733 条范围索引记录。

v9 的默认日期请求在此样本上 37.5 秒后返回 HTTP 500。对账基准改用同一份冻结数据独立计算。导出样本中的每个会话、机器组恰有一份来源，参考程序先核对分片顺序、长度和摘要，再按报告时区与半开区间逐条做整数加总。对照字段包括总量、输入、缓存输入、缓存写入、输出、推理、会话数、无时间事实和未知 Token 事实。六组请求对账全部一致。多 Home 选择、冲突、删除以及后到事实由聚焦测试覆盖。

## 自动刷新

最终构建按中心的默认 10 秒请求预算运行。Chrome 打开概览并加载机器用量卡片，首轮与随后三次一分钟自动刷新均为 HTTP 200。约 184 秒的观察窗口内，三次新的 `computed_at_ms` 均已读回，缓存为 `ready` 且未过期，页面持续显示 4 台机器。90 天范围同期也完成三轮后台重算，缓存状态和冻结样本的账目保持一致。

最终构建重启用时约 4.1 秒，`db check` 通过。临时浏览会话注销后，受保护接口返回 401。候选仅在隔离 DEV 环境运行，生产和共享 DEV 的 schema 均为 v9。脱敏结论在本页，原始对照与计划记录保存在私有忽略目录 `.artifacts/too-725/`。
