# TOO-697 Server SQL 与调度优化验收

日期：2026-11-08。范围为 Server、内嵌 Web 与 schema v7。任务：[TOO-697](https://linear.app/sisyphus-sq/issue/TOO-697)。测试机器为 SQMC04，数据库是 SeekDB 1.2.0 的 MySQL 兼容协议，不是独立 MySQL 8.4。

## 实现与稳定性边界

- 新增租约、发布清理、来源任务、publication generation 四个索引。旧 SQL 字节不变；`.gitattributes` 固定 SQL 检出为 LF，迁移额外接受现场确认的 v6 CRLF 摘要，未知摘要拒绝。
- 发布事务提交后即时唤醒；有工作时一秒轮询，空闲退避至五秒，跨实例仍靠轮询恢复。版本回收保持与本进程构建串行，成功后五分钟，失败/超时一分钟重试，单次五秒预算。
- 已发布分片独立每十五秒清理，单轮最多 16 × 250 片、五秒预算；只选任务元数据，保留 pending/failed 分片和确认收据。
- 年度统计活跃时五分钟刷新，年度和来源统计不再无访问预热；五分钟无访问停止刷新，返回后可先读旧值并触发后台刷新。用量与当前统计仍每分钟预热。年度 HTTP 元信息仍每分钟读取，避免叠加五分钟显示延迟。额度自动读取从三十秒改为六十秒。
- 不改变事实口径、鉴权、配对、仲裁或保留周期，不新增依赖。并非所有扫描都可被索引消除：历史版本 GC 外层和全年统计仍需扫描，主要通过降低频率与预算限制控制负载。
