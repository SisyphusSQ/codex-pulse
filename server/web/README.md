# Codex Pulse Web

React 19 / TypeScript 7 / Vite 8 / AntD 6 / ECharts 6。依赖固定在 package.json 与 package-lock.json，Node 要求 >=22.22.2；标准安装使用 npm ci。React Router HashRouter 的深链接只请求静态壳，数据走同源 v1 API。

独立设计评审入口：`npm --prefix server/web run storybook`（仓库根目录），只监听`http://127.0.0.1:6007/`。含全部9页、8个关键状态与5个公共组件；无需Server/数据库，所有资料和操作均为合成内存预览。2026-10-03用户批准后，相应设计已接入下述业务页面；业务入口不导入设计目录或样本。详见[全站设计稿](../../docs/design/details/multi-machine-reporting/storybook-design.md)。静态构建用`npm run build-storybook -- --output-dir ../../.artifacts/storybook`，默认`storybook-static`也已忽略。

正式 Web 与 Go Server 一起部署：在 `server/` 执行 `make web-install` 后运行 `make build-center`，先生成 `web/dist` 再通过 Go `embed` 编入 Server。按 [中心说明](../README.md)运行 `make run-center`，启动自动准备表结构，直接打开 `http://127.0.0.1:8080/`。运行机器无需 Node、Vite 或 Web 目录；页面与 `/api/v1` 使用同一入口。只运行 `npm run build` 不会更新已构建的 Server，页面变更需要重新构建二进制并重启。

仅在需要前端热更新开发时使用 Vite，部署不使用此入口：

```sh
cd server/web
npm ci
npm run dev
```

Vite 默认把 `/api` 转发到 `http://127.0.0.1:8080`，保留 Host/Origin。这类本地开发需要在私有 Server 配置的 `server.origins` 中额外加入实际 Vite 入口，如 `http://localhost:5173`；默认单体配置只允许中心自身入口。CORS 默认 `*` 且不允许跨域 Cookie，Vite 页面仍通过自身同源代理使用 Cookie。仅供 Vite 的 `PULSE_WEB_PROXY_TARGET` 可指定已授权中心；它不进入静态包，不包含凭据。

首次管理员在受信任服务端终端运行 `codex-pulse-server db bootstrap`，在 Web 输入短期浏览器配对码。采集设备码不能登录管理页面。凭证只在 HttpOnly Cookie，CSRF 只在内存；刷新后重新读取会话。退出只有服务端撤销成功才返回授权页，网络失败保持可操作错误；撤销/过期取消旧请求、清除内存缓存。

未授权浏览器直接打开中心首页即可看到授权表单，无须先进入管理页面取码。首次码及全部浏览器授权失效后的恢复码由 Server 终端生成，命令须使用运行中服务的同一配置与数据库；10 分钟一次性码交换为当前 14 天浏览器会话。详细步骤、入口绑定与恢复说明见[首次浏览器授权与访问恢复](../README.md#首次浏览器授权与访问恢复)。

不把 code/credential/CSRF 放 localStorage、sessionStorage、URL、控制台、环境变量或构建产物。Token/微美元字符串与 NULL 原样保留；前端只格式化与展示，业务聚合、仲裁和预测来自 Server。

```sh
npm run typecheck
npm test
npm run lint:antd
npm run build
```

按开发风险选择验证，提交推送收尾不重复测试。dist/node_modules/.vite 不提交；Server 内嵌并同源托管 Web，更新与回滚仅切换匹配配置和 schema 的二进制，详见[运行说明](../docs/test/operations.md)。

2026-10-01：8 个授权/client UI 测试、类型、构建、AntD lint 通过；所有锁定依赖来自 registry.npmjs.org，审计未报告漏洞。环回 HTTP/隔离 SQLite/合成一次性码的真实浏览器配对、刷新恢复、退出撤销和 390px 窄屏通过；没有读取 Codex Home 或个人/Agent 凭据。三机真实 Home、MySQL、完整看板未验收，业务页面由其余 Execution 卡继续接入。
## 用量总览

首页通过中心 summary API 读取范围 KPI、自然日趋势、Provider/模型构成及独立 365 日热力图。日期、时区、Provider 和采集来源由 Server 筛选。底层保留 Token/微美元的完整十进制字符串；中文页面的 Token 与 Mac 一致使用万/亿、最多一位小数，成本显示 USD 两位小数。格式化使用 BigInt，浮点转换只用于图表坐标；API 等价成本与账单区分，partial 显示已知小计。

当前范围及年度覆盖分别保留陈旧/未知提示，详细证据可展开。热力图参考掘金的七行日历，正方格随可用宽度增大并铺满容器（最小14px），保留3px 间距、日到六标签、月标与底部蓝色图例，保留全年 365 日；窄屏横向查看，星期标签固定。未知日期使用实心浅灰格，有明确零事实才使用最浅蓝格；成功收批次不代表全量历史。年度总 Token、峰值、活跃与连续天数来自 Server 的 heatmap_activity，收在年度活动统计内。来源与执行归属不同，执行设备缺少证据时显示未知。客户端/模型环图含所有已知正值，图例前 8 项之外有提示；完整表保留未知、零和有符号舍入差额。

图表按路由和 ECharts 模块延迟加载，SVG renderer 随容器尺寸变化并在卸载时释放。tooltip 使用文本 richText，标题/模型/工具名不进入 HTML。刷新失败保留同一筛选下的缓存并标记失败；切换筛选等待对应数据，不把旧范围冒充新范围。

## 项目和会话

两页共用自然日/时区、Provider、来源、字面搜索、精确模型、服务端排序与 10–100 条分页。范围 totals 在分页前由 Server 计算；详情使用相同筛选。会话保留标题、原始 Session ID 和全部采集来源，未关联用量明确没有原始会话身份；没有正文或路径。

桌面采用 AntD Splitter 左列表、右详情，可拖动分隔线，两侧独立滚动。项目内点击会话在右侧原位切换，返回项目恢复页签、会话页码与滚动位置；详情不使用弹窗或抽屉。窄屏逐级进入详情并提供返回列表入口，列表保持挂载以保留位置。列表分页/排序保留所选详情，改变统计范围、搜索或模型筛选则清空旧选择。

项目详情的项目、模型、趋势与分页会话贡献来自一次 Server 只读快照。项目名相同保留独立身份；表格同时显示中心键前缀和成员数。跨页选中关系保存在页面内存，改变统计范围清空选择；关联前确认成员和目标，一次最多 100 个成员。关联/解除均由管理员 CSRF 写接口处理；成功后刷新相关查询并清空选择，失败保留明确错误。解除只恢复各成员独立项目身份，统计事实保留。

## 会话 TPS

列表和详情展示生命周期加权输出 TPS，BigInt 将毫 TPS 舍入为两位小数、毫秒格式化三位秒；真实零与未知区分。详情显示活跃并集口径、覆盖、实际采集来源/冲突、时间依据与最近 10/20/50 轮。日期/模型/分页只筛选用量贡献，不重算 TPS。

## 额度与节奏

额度页按 Provider、确认账号键和采集来源向中心请求；同邮箱的账号同时显示原始 ID，不按邮箱合并。每 30 秒只读取中心已有数据，不触发本机配额刷新。used/remaining、真实窗口、reset、原观测与选中来源均来自 API；额度主值、进度条及实际曲线持续对应最后一次有效更新，超过 10 分钟或 reset 到时后仍可查看；原观测时间常驻，reset 间隔显示观测时的静态值。刷新失败保留对应筛选缓存及原时间，提示失败。

quota 与 pace 是两次独立读快照，各自保留中心读取时间和原观测时间；切换筛选时等待新范围，不拼成一个同时刻结果。按用户最终设计，可信当前周期与上一周期使用普通实线连接已有样本的两端，隐藏密集圆点，不追加now端点；缺失记录仍为NULL，连接线不产生观测、插值事实或预测证据。观测周期曲线与已知指标持续可见；Server 按 snapshot_at_ms 的最后观测时刻计算周期进度、节奏差、历史对比和推算，轮询只改变中心读取时间。推算注明截至最后更新；真实冲突/可疑会保留原因，未知不会补零。历史中位紫虚线、理想节奏灰点线；上下界在提示中可查。四指标、推算与同进度对比按Mac组织，说明图标支持悬停/点击/焦点。上一周期和最多四个历史周期可独立查看；首尾覆盖不代表连续采集。预测状态、时刻、提前量与不可用原因来自 Server。正节奏偏差表示使用快于均匀节奏。

账号列表按确认 account_key 组织；所选账号的额度窗口、reset、Reset Credits 与节奏/来源显示在同一详情中，不使用全局独立 Credits 页签。同邮箱的不同账号保留原始 ID，只有 Credits 而没有窗口的账号仍可查看；未确认身份单列“待关联观测”，各条独立展示，不推断为同一账号。

Credits 以最后观测库存为主；观测时可用数量与最近到期由中心按原观测时刻返回 snapshot_available_inventory / snapshot_next_expires_at_ms。详情完整性、原观测、到期和 reset 保留；到期与额度 reset 含义不同。NULL 与零保留，数量精确格式化，不按来源相加。数据缓存仅在内存，名称普通文本转义。

## 设备与授权

管理页签发用途固定、10 分钟/一次性码；管理用途先确认完整权限。码只在当前弹窗内存，不进入缓存、存储、URL、日志；关闭即时卸载，过期清空，未用码可通过管理员 CSRF 接口撤销，已消费 409 指引核对客户端。客户端列表可改名/撤销，撤销保留历史；撤销当前浏览器调用正常 logout。Form 使用各自 name，保证标签和字段 ID 唯一。

来源状态显示版本、实际采集、最后接收、覆盖边界及积压；索引就绪、收到新批次不代表完整覆盖或机器在线。没有 Provider 状态保持未知；刷新失败保留旧结果并提示。设备/配额/统计查询在管理关系变化后失效重读。

## 价目表与额度用量

价目表默认按官方已确认发布时间从新到旧排列，常驻日期并可展开发布说明；日期未知置后，近30天已使用仅作筛选，价格/历史费用口径保持。价目表覆盖Codex/ChatGPT、Cursor、Grok，分别展示当前公开参考、本机历史快照与已观测未定价模型，并提供订阅套餐参考。费用与Token显示精度沿用Mac，计算继续由Go执行。用量集中为概览、模型、采集来源三个入口，账号独立展示额度/节奏与订阅；模型页有真实模型日趋势、Token分解、估算与上报金额。旧 `/quota?view=usage` 深链保留 Provider/模型参数跳转模型页。

账号订阅设置由中心保存，支持备注、手动套餐、每月续费日/完整到期日和IANA时区；不会修改平台reset或扣款，不与Mac双向同步。修订冲突保留表单并要求重新读取。升级到中心结构v2前按Server运行说明备份并显式db upgrade；HTTP启动不自动改表。
